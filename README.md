# LabTurn ↗

**Твоя очередь сдавать.** Telegram Mini App для очередей на лабораторные и общей ведомости: события, четыре стратегии очереди, оценки, уведомления и журнал изменений. Go + PostgreSQL + React/TypeScript; готовую статику раздаёт Go.

Production: https://labturn.awak3r.ru · Бот: [@labturn_bot](https://t.me/labturn_bot).

Разработка и тесты — только на ПК или GitHub-hosted runners. Production получает готовый образ **только через Actions** из `codex/labturn-mvp`; merge в `main` не требуется. Production-секреты и дампы не переносить на ПК, в Git, artifacts или чат. `DEV_AUTH=true` допустим только на localhost с синтетическими данными.

## Текущие правила

- Root выдаёт/отзывает роль преподавателя. Выбор режима в интерфейсе не выдаёт прав; управление пользователями и журнал изменений — только root.
- Действующий преподаватель работает со всеми группами и предметами **без назначений**: работы, оценки, экспорт и создание событий. Управление приёмом — у владельца события и root. Студент видит ведомость своей группы.
- Сохранение оценки не завершает приём; очередь закрывается отдельной командой. Случайное перемешивание — только root, один раз до первого вызова; результат хранится в БД.
- У работ есть положительный вес и обязательность (по умолчанию `1` / `true`). Пустая обязательная учитывается за `2`; пустая необязательная исключается. Реальная `2` не считается сдачей. Архивные работы не участвуют.
- Итоговая подсказка появляется после сдачи всех обязательных; сервер округляет точный взвешенный средний, половина вверх, без повторного округления отображаемых двух знаков. Это не автоматически выставленная оценка. Полный контракт — в [API](docs/API.md).

Правила назначений и обязательности всех работ из [исторической спецификации](docs/archive/SPEC-v0.3.md) заменены текущим API. Исторические тестовые результаты не подтверждают новый commit автоматически.
