# Подтверждённые дефекты

## BUG-01 — сохранённая оценка откатывается в интерфейсе

Приоритет: высокий; потеря актуального отображения и риск конфликта следующей правки.
Окружение: Chromium, dev Go API/PostgreSQL, исходная версия 3329c37.
Шаги и регрессия: QA-01, `web/tests/recovery.spec.ts`.
До исправления: POST вернул 200, но ячейка вместо «5» показала пустое значение.
Причина: refresh пропускал запрос после мутации, если уже выполнялся фоновый GET;
локальная ожидающая правка удалялась до получения свежей версии ведомости.
Исправление: принудительное чтение после мутаций, игнорирование устаревших ответов,
сохранение ожидающей правки до подтверждённого свежего снимка.
