# Проверки первой реализации

Последующий аудит с проверкой сетевых сбоев и отзывов доступа: [QA-отчёт](qa/REPORT.md).
В нём описано исправление гонки обновления ведомости и результаты расширенного набора тестов.

Проведены локально на PostgreSQL 17:

- `go test -race -count=1 ./...` — успешно; unit и интеграционные сценарии.
- `go vet ./...` — успешно.
- `npm run build` — успешно; TypeScript и production Vite bundle.
- Playwright / системный Chromium — 5 сценариев успешно: desktop, mobile 390px, автосохранение оценки отдельно от завершения приёма, запрет самостоятельного получения роли, root-перемешивание один раз.
- 100 пользователей и 10 событий — все параллельные запросы выполнены без дубликатов. Этот тест проверяет корректность под нагрузкой, а не гарантирует задержку интерфейса 5 секунд.
- `pg_dump` и восстановление в отдельную БД — успешно, события восстановлены.
- Telegram `getMe` — токен действителен, бот `@labturn_bot`. Реальную доставку сообщений и Telegram Mini App ещё нужно проверить после настройки HTTPS и root ID.

Полная многоэтапная Docker-сборка в текущем Cloud-окружении не завершена: rootless Docker использует VFS, копии слоёв исчерпывают лимит диска. При пробной сборке также потребовался сертификат прокси среды; он подключался как временный BuildKit secret, исходный Dockerfile не менялся. Нативные frontend/backend сборки прошли. В GitHub Actions добавлена проверка Docker-сборки в обычном окружении.

Демонстрационная Sites-версия — отдельное browser-only приложение с тестовыми данными. Она не заменяет Go/PostgreSQL и не содержит токен бота.
