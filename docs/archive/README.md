# Архив LabTurn

Исторические требования, миграция и результаты проверок. Даты, SHA, промежуточные ошибки и ограничения сохранены как evidence, **не как текущие инструкции или подтверждение нового релиза**. Старые правила назначений преподавателей и обязательности всех работ заменены [API](../API.md).

Текущие документы: [README](../../README.md), [разработка](../DEVELOPMENT.md), [production](../DEPLOYMENT.md), [статус и ручные проверки](../STATUS.md). Сохраняемый [sandbox](../LOCAL-SANDBOX.md) остаётся операционным документом; `.local/` не входит в архив и не удаляется.

Пути `/tmp/…` в свидетельстве — временные логи, не долговечные artifacts. `.local/sandbox/…` — файлы только на ПК владельца, не гарантированно доступны из свежего clone. Их содержимое не скопировано в Git. Внешние Actions-ссылки сохраняют привязку к конкретному run, а не к текущему состоянию ветки.
